检测到其他温控模块

    温控类模块会争抢同一批资源（emul_temp / horae 服务 / shell-temp / sys_thermal* XML / cooling_device）。装多个不会叠加效果，只会互相覆盖 —— 表现为温控行为随机、亮度异常等难以复现的问题。建议只保留一个。
